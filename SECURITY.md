# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

This project processes publicly available NYC TLC taxi trip data and does not
handle sensitive personal information. However, if you discover a security
vulnerability, please report it by emailing caizefan@sjtu.edu.cn.

Please do not file public GitHub issues for security vulnerabilities.

You should receive a response within 48 hours. If the issue is confirmed, a
patch will be released as soon as possible depending on complexity.
