# 第三题：开放拓展

在此目录完成一项与出租车订单或区域决策相关的拓展。每项拓展都应包含：

- 明确的问题背景、输入、输出、数据和基本假设；
- 可运行的方法实现及主要参数；
- 至少一种合理的对照方法；
- 与问题匹配的评价指标和对比实验；
- 结果分析、局限和可能的改进；
- 数据来源、依赖和复现主要结果的命令。

可选方向包括：

1. 多步规划、搜索或效率优化；
2. 数据分析与交互式推荐系统；
3. 需求、车费或接单概率预测；
4. 多车辆模拟与联合调度；
5. 强化学习策略；
6. 自拟题目。

每个方向的具体完成项和实验要求见项目根目录的[项目说明书与评分细则](../../项目说明书与评分细则.md)第 8 节。

选择深度学习或强化学习本身不会自动获得高分；重点是问题定义、合理对比、结果分析和可复现性。

如果选择需求预测、收入预测或强化学习等需要更多数据的方向，建议额外下载连续多个月份的 NYC TLC Yellow Taxi 订单，并按时间顺序划分训练、验证和测试。在本目录的 README 中写明额外数据的来源、月份、下载方法和时间划分。

强化学习方向可以参考 `src/eval/rollout_core.py` 构建训练环境，也可以修改状态、动作、奖励和转移
规则，但须说明与公开 rollout 的差异并避免数据泄漏。能够适配统一接口时，应补充未修改的
validation rollout 结果；否则应在同一独立测试环境中公平比较 RL 与对照策略。

完成两项内容完整且相互独立的拓展任务，项目总分可额外获得 5 分 Bonus。
如果完成两项，请分别建立子目录，为每项任务单独提供 README、运行命令和结果文件。
