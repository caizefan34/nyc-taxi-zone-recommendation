Platform Capabilities

What This Platform Does

A complete decision intelligence pipeline — from raw trip data to deployable policies with rigorous evaluation.

NYC TLC Data → Demand Forecasting → Supply-Demand Model → Multi-Agent Sim → Policy Optimization → Evaluation (OPE) → API / Dashboard
📈

Demand Forecasting

Leakage-safe LightGBM + XGBoost ensemble with GraphSAGE/GAT spatial features. Strictly-prior temporal splits. MAE 1.49.

LightGBMXGBoostGraphSAGE
🌆

Multi-Agent Simulation

Configurable fleet with finite demand, explicit competition, shift constraints, and calibrated travel times. Tests policies under market pressure.

v2 Engine50+ drivers
🧠

Reinforcement Learning

DQN, Double DQN, and IQL with Gymnasium environment. Masked actions, offline replay buffers, and trajectory-aware training.

DQNDouble DQNIQL
🔬

Offline Policy Evaluation

Trajectory-level Weighted Importance Sampling and sequential Doubly Robust estimation with bootstrap confidence intervals.

WISDoubly RobustBootstrap CI

Quick Start

Run It Locally

One command to start the full platform with API and interactive demo.

# Clone and start (API + Demo)
git clone https://github.com/caizefan34/nyc-taxi-zone-recommendation.git
cd nyc-taxi-zone-recommendation
docker compose up

# API → http://localhost:8000/docs
# Demo → http://localhost:8501
