What This Platform Does

A complete decision intelligence pipeline — from raw trip data to deployable policies with rigorous evaluation.

📈

Demand Forecasting

Leakage-safe LightGBM + XGBoost ensemble with GraphSAGE/GAT spatial features. Strictly-prior temporal splits prevent data leakage. MAE 1.49 on 263-zone NYC predictions.

LightGBMXGBoostGraphSAGE

🌆

Multi-Agent Simulation

Configurable fleet simulator with finite depletable demand, explicit competition, shift constraints, and calibrated travel times. Tests policies under realistic market pressure.

v2 Engine50+ drivers

🧠

Reinforcement Learning

DQN, Double DQN, and Implicit Q-Learning (IQL) with Gymnasium environment. Masked action spaces, offline replay buffers, and trajectory-aware evaluation.

DQNDouble DQNIQL

🔬

Offline Policy Evaluation

Trajectory-level Weighted Importance Sampling and sequential Doubly Robust estimation with complete-trajectory bootstrap confidence intervals. FQE diagnostic for nuisance models.

WISDoubly RobustBootstrap CI

End-to-end pipeline for urban mobility intelligence.

1

Data Pipeline

Raw NYC TLC trips → chronological split → cleaning → zone-time statistics → travel-time matrix

2

Demand Forecasting

Feature engineering → LightGBM + XGBoost ensemble → GraphSAGE/GAT spatial encoding → recursive holdout predictions

3

Policy Optimization

Two-step MDP planning · DQN · Double DQN · IQL offline RL · Model-based value iteration

4

Evaluation & Deploy

Paired statistical tests · Offline OPE (WIS/DR) · Exposure analysis · REST API · Docker deploy
